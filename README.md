# Georgina McLeod — Spatial & Experiential Design Portfolio

Responsive static portfolio built with HTML, CSS and JavaScript. No build tools or install steps are required. All project imagery is stored locally in `assets/projects/` and optimized for web use.

## Preview locally

Open `index.html` in a browser. The project filters, image galleries and mobile navigation work without a server.

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Upload the **contents** of this folder (`index.html`, `styles.css`, `script.js`, and `assets/`) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will provide the published URL after deployment.

## Update project content

Project summaries, captions and image sequences are in `script.js`. Project images are grouped in `assets/projects/`. Keep the image filenames and paths in sync when adding or replacing images.
